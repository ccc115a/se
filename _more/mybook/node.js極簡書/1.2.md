# 1.2 安裝與版本管理

## 直接安裝（不推薦）

到 [nodejs.org](https://nodejs.org) 下載安裝檔。能用，但有一個問題：**電腦上只能有一個 Node 版本**。不同專案可能需要不同版本，切換很痛苦。

## 推薦：用 nvm 管理版本

**nvm（Node Version Manager）** 讓你安裝多個 Node 版本，並隨時切換。

**第一步：安裝 nvm**

```bash
# macOS / Linux
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/master/install.sh | bash

# Windows 用 nvm-windows：到 github.com/coreybutler/nvm-windows 下載
```

安裝後重開終端機生效。

**第二步：安裝與使用 Node**

```bash
nvm install --lts    # 安裝最新 LTS（長期支援）版本
nvm install 22       # 安裝指定版本
nvm use 22           # 切換到指定版本
nvm ls               # 查看已安裝的版本
```

## 版本怎麼選？

| 版本類型 | 說明 | 建議 |
|---|---|---|
| LTS | 長期支援版，穩定、維護 30 個月 | **正式專案用這個** |
| Current | 最新版，有新功能但不保證穩定 | 試驗新特性時用 |

驗證安裝：

```bash
node -v    # v22.x.x
npm -v     # 10.x.x（npm 會跟著 Node 一起裝好）
```

## .nvmrc：專案固定版本

在專案根目錄放一個 `.nvmrc` 檔，內容只有版本號：

```
22
```

之後進專案執行：

```bash
nvm use    # 自動讀取 .nvmrc 並切換版本
```

> 團隊協作時把 `.nvmrc` 提交進 Git，所有人用同一個版本，避免「在我電腦上可以跑」的版本差異問題。
