# 4.1 連接遠端儲存庫

## 兩種起點

**起點 A：本地專案要推上 GitHub**

先在 GitHub 網頁上建立一個空儲存庫（不要勾選自動生成 README），然後：

```bash
git remote add origin git@github.com:你的帳號/my-project.git
git push -u origin main
```

- `git remote add origin <URL>`：把遠端儲存庫取名為 `origin`（慣例名稱，代表「你的主要遠端庫」）
- `git push -u origin main`：把本地 main 推上去，`-u` 是設定上游追蹤，之後只需打 `git push` 即可

**起點 B：從 GitHub 下載遠端專案**

```bash
git clone git@github.com:某個帳號/some-project.git
```

`git clone` 會把整個儲存庫（含完整歷史）下載下來，並自動設定好 `origin` 遠端，直接就能開始工作。

## 查看與管理遠端

```bash
git remote -v        # 查看目前已設定的遠端庫
git remote remove origin   # 移除遠端設定
```

## HTTPS 還是 SSH？

| | SSH | HTTPS |
|---|---|---|
| 網址 | `git@github.com:帳號/repo.git` | `https://github.com/帳號/repo.git` |
| 認證 | SSH Key（設定一次永久免密碼） | 帳號密碼或 Personal Access Token |
| 建議 | 個人開發機 | 環境受限時（如公司防火牆擋 22 port） |

> 在 GitHub 上複製網址時，按綠色 `<> Code` 按鈕可切換 SSH / HTTPS 格式。
