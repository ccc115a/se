# 3.2 分支基本操作

## 建立與切換分支

現代推薦用 `git switch`（語意清楚，專門做切換）：

```bash
git switch -c feature/login    # 建立並切換到新分支（-c = create）
git switch main                # 切回 main
```

舊式的寫法（效果相同，很多舊教學還在用）：

```bash
git branch feature/login       # 只建立分支，不切換
git checkout feature/login     # 切換分支
git checkout -b feature/login  # 建立並切換
```

## 查看目前所有分支：git branch -a

```bash
git branch        # 只看本地分支
git branch -a     # 看本地 + 遠端所有分支
```

輸出範例：

```
* main
  feature/login
  fix/safari-form
  remotes/origin/main
```

`*` 號標示你目前在的分支。

## 分支命名習慣

用 `/` 分隔類型與描述，一看就知道這條分支在做什麼：

```
feature/user-login     新功能
fix/null-pointer       修 bug
hotfix/crash-on-start  緊急修復
```

## 一個完整的分支工作流程

```bash
git switch main              # 1. 從最新的 main 開始
git switch -c feature/login  # 2. 建立功能分支
# ...寫程式碼...
git add .                    # 3. 提交變更（可多次）
git commit -m "完成登入表單"
git commit -m "加上驗證邏輯"
git switch main              # 4. 回到 main 準備合併
git merge feature/login      # 5. 合併（見下一節）
```

> 建議：分支的生命週期不要太長，功能完成就合併回 main。拖太久的分支，合併時衝突會更多。
