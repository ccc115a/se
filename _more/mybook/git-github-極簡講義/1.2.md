# 1.2 5 分鐘環境設定

## 安裝 Git

- **macOS**：`xcode-select --install` 或 `brew install git`
- **Windows**：到 [git-scm.com](https://git-scm.com) 下載安裝檔，一路按下一步即可
- **Linux**：`sudo apt install git`（Ubuntu/Debian）

安裝完成後驗證：

```bash
git --version
# git version 2.46.0
```

## 告訴 Git 你是誰

每次 commit 都會記錄作者資訊，所以先做基本設定（只需要做一次）：

```bash
git config --global user.name "你的名字"
git config --global user.email "你的 email"
```

> 注意：email 建議使用你在 GitHub 上的註冊信箱，這樣 GitHub 才能正確把 commit 關聯到你的帳號。

檢查設定結果：

```bash
git config --global list
```

## 設定 SSH Key 輕鬆連線 GitHub

沒有 SSH Key 之前，每次 push 都要輸入帳號密碼。設定一次，之後永久免密碼。

**第一步：產生 SSH Key**

```bash
ssh-keygen -t ed25519 -C "你的 email"
```

一路按 Enter 使用預設值即可。金鑰會存在 `~/.ssh/` 目錄下。

**第二步：把公鑰加到 GitHub**

1. 複製公鑰內容：

```bash
cat ~/.ssh/id_ed25519.pub
```

2. 到 GitHub → 右上角頭像 → **Settings** → **SSH and GPG keys** → **New SSH key**，把剛才複製的內容貼上，儲存。

**第三步：測試連線**

```bash
ssh -T git@github.com
# Hi 你的帳號! You've successfully authenticated...
```

看到成功的訊息，環境設定就完成了。

>macOS 使用者也可以用 `brew install gh` 安裝 GitHub CLI，執行 `gh auth login` 一次搞定認證與 SSH 設定。
