# 6.1 最常使用的 12 個 Git 指令

日常開發 90% 的時間，你只會用到這 12 個指令：

| # | 指令 | 用途 |
|---|---|---|
| 1 | `git status` | 查看目前檔案狀態（不知道狀況就先打它） |
| 2 | `git add .` | 把所有變更加入暫存區 |
| 3 | `git commit -m "說明"` | 提交版本歷史 |
| 4 | `git log --oneline` | 查看簡潔的提交紀錄 |
| 5 | `git diff` | 比對還沒 add 的變更 |
| 6 | `git switch -c <branch>` | 建立並切換新分支 |
| 7 | `git switch main` | 切回 main 分支 |
| 8 | `git merge <branch>` | 合併分支 |
| 9 | `git pull` | 下載並合併遠端最新狀態 |
| 10 | `git push` | 推送本地提交到遠端 |
| 11 | `git restore <file>` | 放棄工作區的修改 |
| 12 | `git stash` / `git stash pop` | 收起／放回未完成的修改 |

## 按場景記憶

**每天的基本節奏：**

```bash
git status → git add . → git commit -m "說明" → git push
```

**開始新功能：**

```bash
git switch main && git pull
git switch -c feature/xxx
```

**功能完成：**

```bash
git add . && git commit -m "完成 xxx"
git push -u origin feature/xxx
# → 到 GitHub 發 PR
```

**修壞了要後悔：**

```bash
git restore <file>          # 放棄修改
git restore --staged <file> # 移出暫存區
git reflog                  # 大災難救援
```
